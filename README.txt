حمولة HAMOOLA — النسخة التجريبية الأولى

المحتويات:
- index.html: واجهة التطبيق التفاعلية.
- manifest.webmanifest و sw.js: دعم التثبيت كتطبيق ويب تقدمي عند استضافته عبر HTTPS.

التجربة:
1) افتح index.html في متصفح حديث لمعاينة الواجهات.
2) النشر والحجز يعملان محلياً داخل الصفحة فقط.
3) لتثبيته على الهاتف كـ PWA، يجب رفع الملفات إلى استضافة HTTPS ثم اختيار "إضافة إلى الشاشة الرئيسية" من المتصفح.

حدود النسخة:
- لا توجد حسابات مستخدمين حقيقية أو قاعدة بيانات مشتركة.
- لا توجد محادثات أو خرائط حية أو رفع وثائق أو تحقق هوية.
- لا توجد محفظة أو بوابة دفع أو خصم عمولة حقيقي.
- بيانات الأحمال والحجوزات تجريبية وتختفي عند إعادة تحميل الصفحة.
- لوحة الإدارة للعرض فقط وليست لوحة تشغيل آمنة.
